PreToolUse hook returns permissionDecision "deny" + reason. Effect?	Tool call is blocked. The reason is shown to Claude, so it can adapt (e.g. use the safe wrapper).
PreToolUse permissionDecision "allow" vs "ask": who sees the reason?	The user. allow = runs, skips the prompt. ask = user confirms.
Can a PostToolUse hook stop a dangerous call?	No. It runs after the tool already ran. Use PreToolUse to block. PostToolUse is for normalizing/checking results.

How does a subagent get the context it needs?	Explicitly in its prompt. It does not see the coordinator's conversation.

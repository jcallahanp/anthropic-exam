1. Who needs it? Only me → ~. Team or CI → repo file.
2. Always, or sometimes? Always → CLAUDE.md. On demand → skill or command.
3. Where does it apply? One folder → folder CLAUDE.md. A file type spread out → rules + paths:.
Test-takers say: D3 catches people who use Claude Code daily. CLI flags, CI headless mode, the CLAUDE.md hierarchy, and “hook vs CLAUDE.md vs permission” come up most.
